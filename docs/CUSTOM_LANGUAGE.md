# WinActionRecorder 自定义指令语言

自定义指令是一种小型、逐行执行的本地自动化语言。它适合表达“点击一下、等一会、
按一个键、重复若干次”这类流程。它有自己的受限数值表达式、变量与函数解析器，不会
调用 Python `eval`，也不能导入模块、访问对象、读写文件、联网或调用系统命令。

## 快速开始

```text
# 左键点击 10 次；每次按住 35 ms，两次点击之间等待 200 ms
mouse left[last:35ms, count:10, interval:200ms]
```

在应用的“自定义”页把代码粘贴到编辑器，先单击“校验”，再单击“运行方案”。运行中
可以暂停、继续或停止；自定义页激活时，F9 会运行、暂停或继续当前方案。方案已经运行
后，F9 会持续优先控制它。Esc 会紧急停止当前方案，并触发输入释放清理。

每行只能写一条命令。空行会被忽略；命令不区分大小写，但普通字符按键会保留原字符。
命令前可加一个 `/`，因此 `mouse left` 与 `/mouse left` 等价。`#` 和 `//` 后面的内容
是注释：

```text
/mouse left       # Minecraft 风格的斜杠前缀
next 250ms        // 等待四分之一秒
key A             # 输入大写字符 A
```

## 数值表达式与变量

用 `let 名称 = 表达式` 定义编译期数值变量：

```text
let base = 500ms
let jitter = base / 2
let repeats = 2 + 3

next base random jitter
repeat repeats {
  key f[last:base / 5]
}
```

表达式支持 `+`、`-`、`*`、`/`、`%`、正负号和括号，遵循先乘除后加减的常见优先级。
`ms`、`s` 会在解析时统一换算成毫秒，因此 `1s / 4` 是 `250ms`，
`500ms + 0.5s` 是 `1000ms`。除以 0、对 0 取余、非有限结果和超出具体命令范围的结果
都会在运行前报错。

变量名使用英文字母、数字和下划线，不能以数字开头，也不能占用命令保留字；名称不
区分大小写。变量从声明处开始对后续语句可见，可以用新的 `let` 覆盖后续使用的值。
函数内声明的局部变量只在该次函数调用中有效，不会泄漏到调用位置之后。

数值表达式可用于：

- `next`/`wait` 的基础时长和 `random` 偏移；
- `repeat` 次数（最终结果必须是整数）；
- 鼠标点击的 `last`、`count`、`interval`、`after`；
- 鼠标坐标、滚轮量；
- `key`/`hotkey` 的 `last`。

坐标一行需要连续读取两个值。简单变量可以直接写 `mouse move x y`；某个坐标若是
复合算式，请用括号明确边界，例如：

```text
let x = 800
let y = 450
mouse move (x + 20) (y - 10)
mouse scroll 0 -3 at x y
```

## 可复用函数

函数只在脚本最外层声明，用 `call` 调用。参数是安全数值表达式，函数没有返回值：

```text
function burst(times, gap) {
  repeat times {
    key f[last:gap / 8]
    next gap random gap / 4
  }
}

call burst(3, 240ms)
call burst(2, 1s / 2)
```

也可以写 `func` 作为 `function` 的别名。函数允许先调用、后声明；参数会遮蔽同名外层
变量。函数可调用其他函数，但禁止直接或间接递归，默认调用深度最多 32 层；编译后的
全部输入动作仍受 100000 动作上限约束，因此函数不会绕过循环和资源限制。函数参数
目前仅支持数值，按键名和鼠标按钮仍需在函数体中明确写出。

## 命令参考

### `next` / `wait`：等待

```text
next
next 250ms
next 1.5s
next 0.5s random 0.25s
wait 500
```

- `next` 和 `wait` 完全等价。
- 不写时长时默认等待 100 ms。
- `ms` 表示毫秒，`s` 表示秒；不写单位时也按毫秒解释。
- 数值必须紧跟单位，例如写 `1.5s`，不能写 `1.5 s`。
- 时长可以使用前述变量和算术表达式。
- 等待可以是 0，但持续循环应保留合理间隔，避免给目标程序造成过高输入负载。
- 在时长后写 `random 偏移量` 会在每次执行时独立抽取 `±偏移量`。例如
  `next 0.5s random 0.25s` 会均匀随机等待 `0.25s～0.75s`。
- 随机偏移不能大于基础等待；基础等待加偏移也不能超过等待上限，因此结果永远非负且
  不会借随机范围绕过资源限制。循环的每一轮都会重新抽样，暂停时间不计入等待。

等待发生在下一条输入动作之前。脚本末尾的等待也会执行完毕后再结束。

### `mouse`：鼠标

在当前光标位置单击：

```text
mouse left
mouse right
mouse middle
```

旧写法保持兼容，等价于按住 20 ms 后释放一次。需要精确控制时，在按钮名后加入方括号
参数：

```text
mouse left[last:10ms]
mouse left[last:25ms, count:2, interval:80ms]
mouse right[last:60ms, count:5, interval:300ms, after:1s]
```

参数顺序可以调整，逗号、冒号和方括号两侧可以留空格。`hold` 是 `last` 的兼容别名，
但应用生成的新指令统一使用 `last`。参数值可使用变量和算术；每个参数只能出现一次：

| 参数 | 含义 | 默认值 | 范围 |
| --- | --- | ---: | ---: |
| `last` | 一次按下到释放之间的保持时长 | 20 ms | 1～60000 ms |
| `count` | 这一条命令连续完成的点击次数 | 1 | 1～10000 |
| `interval` | 同一条命令内，上一次释放到下一次按下的等待 | 100 ms | 0～86400000 ms |
| `after` | 最后一次释放到下一条命令的等待 | 0 ms | 0～86400000 ms |

`interval` 只在 `count` 大于 1 时产生间隔；`after` 会和紧随其后的 `next`/`wait`
累加。首次按下不会额外等待 `interval`，最后一次释放后也不会再等待 `interval`。

例如：

```text
mouse left[last:10ms, count:2, interval:80ms, after:200ms]
key space
```

执行顺序是：左键按下 → 保持 10 ms → 释放 → 等待 80 ms → 第二次按下 → 保持
10 ms → 释放 → 等待 200 ms → 按空格。这里的时间由应用按 1 倍执行，不会套用普通
录制回放页的速度倍率。

移动到绝对物理像素坐标后单击：

```text
mouse left at 800 450
mouse right[last:40ms, count:3, interval:500ms] at -120 600
```

只移动鼠标，不点击：

```text
mouse move 800 450
```

滚动当前光标所在位置，或先移动到固定坐标再滚动：

```text
mouse scroll 0 -3
mouse scroll 2 0 at 800 450
```

`mouse scroll DX DY` 中，`DX` 是水平滚动量、`DY` 是垂直滚动量；正负方向由
Windows 和目标程序解释，二者不能同时为 0。`at X Y` 可省略；写出时会先移动到该
绝对物理像素坐标，再执行滚动。滚动量与坐标均为有符号 32 位整数。

支持 `left`、`right` 和 `middle` 三种按钮。参数方括号必须写在按钮名之后、可选的
`at X Y` 之前。坐标是有符号 32 位整数；运行前还会按当前真实显示器区域校验，落在
虚拟桌面之外或多显示器之间空白区域的坐标不会执行。

自定义指令中的显式坐标是绝对坐标，不使用连点器“切屏后按当前画面等比适配”的
`ClipCursor` 映射。需要在另一台电脑或不同显示器布局上使用时，应重新检查坐标。

### 鼠标指令积木

“自定义”页的代码编辑器上方提供可视化鼠标指令积木。选择鼠标按钮，填写 `last`、
`count`、`interval`、`after` 和可选固定坐标后，界面会同时显示规范 DSL 与
“按下 → 保持 → 释放”的流程预览。

- “插入指令”在当前光标位置加入一条新命令；
- 光标位于可识别的鼠标点击行时，积木会回填该行参数；
- “更新当前行”用积木中的参数替换该行，并保留原有缩进、可选 `/` 前缀和尾注释；
- 运行方案期间积木和代码编辑器一起锁定，停止后恢复。

积木只是安全的源码生成/编辑工具：最终仍会经过与手写源码完全相同的解析、资源上限
和坐标校验，不会绕过编译器。积木只回填可无损表示的字面量鼠标行；包含变量或算术的
合法鼠标行应直接在源码编辑器中修改，积木不会擅自把表达式改写成当前计算结果。

### `key`：单键与显式按键状态

```text
key a
key A
key space
key enter
key f5
key vk:174
key f[last:80ms]
```

普通 `key 名称` 会按下并释放一个键，默认按住 30 ms。可用 `last`（或别名
`hold`）把保持时间设为 1～60000 ms：

```text
key space[last:120ms]
key f[hold:80ms]
```

需要让修饰键跨越多条命令时，可显式控制按下与释放：

```text
key down ctrl
key c[last:50ms]
key up ctrl
```

显式状态命令不接受 `last`；需要停留时在两条命令之间写 `next`。`key down` 和
`key up` 若没有第三个按键名，仍按旧语义点击方向键 Down/Up。运行结束、停止、Esc、
异常或关闭窗口时，执行器会释放仍处于按下状态的键。

按键名称支持：

- 任意单个普通字符，例如 `a`、`A`、`1` 或 `中`；
- `space`、`enter`、`tab`、`backspace`、`delete`、`insert`、`esc`；
- `up`、`down`、`left`、`right`、`home`、`end`、`page_up`、`page_down`；
- `shift`、`ctrl`、`alt`、`cmd` 及其 `_l`、`_r` 变体；
- `f1` 到 `f24`；
- `caps_lock`、`num_lock`、`scroll_lock`、`print_screen`、`pause`、`menu`；
- `media_play_pause`、`media_next`、`media_previous`、`media_volume_up`、
  `media_volume_down`、`media_volume_mute`；
- `vk:0` 到 `vk:65535` 形式的 Windows 虚拟键码。

特殊键名也可带 `key.` 前缀，例如 `key key.enter`。`return`/`enter`、`escape`/`esc`、
`control`/`ctrl`、`windows`/`win`/`cmd`、`pageup`/`page_up` 和
`pagedown`/`page_down` 是可用别名。

### `hotkey`：组合键

```text
hotkey ctrl c
hotkey ctrl shift s[last:80ms]
```

`hotkey` 至少需要两个、最多 16 个不重复的按键。它按书写顺序依次按下所有键，保持
默认 30 ms（或 `last` 指定的时长），再按相反顺序释放。例如第二条会按下 Ctrl、
Shift、S，再释放 S、Shift、Ctrl。停止或异常发生在保持期间时，同样会反序清理。

`key ctrl+c` 仍不是合法写法；请写 `hotkey ctrl c`。方括号本身若需要作为组合键成员，
可使用对应的 `vk:` 虚拟键码，避免与 `last` 选项方括号混淆。

### `repeat`：固定次数循环

```text
repeat 5 {
  key space
  next 1s
}
```

次数可以是数值表达式，但最终结果必须是 1 到 10000 的整数。左花括号后请换行书写
块内命令，右花括号单独放在块结束处。循环可以嵌套。

### `while true`：持续循环

```text
while true {
  mouse left
  next 100ms
}
```

这是唯一支持的 `while` 条件。它会持续执行，直到单击停止、按 Esc、关闭应用或触发
安全上限。空循环和只包含零时长等待的忙循环会在运行前被拒绝；无限循环之后不能再写
永远无法到达的命令。

### `break`：退出当前循环

```text
repeat 10 {
  mouse right
  break
}
key enter
```

`break` 只能写在 `repeat` 或 `while true` 块内，并退出最内层循环。当前语言没有条件
表达式，因此直接写在 `while true` 中的 `break` 会让该循环执行到 `break` 一次后结束：

```text
while true {
  mouse right
  break
}
key enter
```

## 完整示例

### 定点右键十次

```text
mouse right[last:40ms, count:10, interval:500ms] at 800 450
```

请把 `800 450` 改成当前电脑上的安全目标坐标，再运行。

### 移动、点击并按键

```text
mouse move 640 360
next 300ms
mouse left[last:80ms, after:500ms]
key space
```

### 带斜杠和注释的持续连点

```text
// 停止按钮或 Esc 结束
/while true {
  /mouse left[last:20ms, after:120ms]
}
```

### 用变量和函数复用按键节奏

```text
let rounds = 3
let gap = 240ms

function burst(times, delay) {
  repeat times {
    key f[last:delay / 8]
    next delay random delay / 4
  }
}

call burst(rounds, gap)
```

## 方案管理

“方案”保存的是名称、说明和自定义指令源码，不是录制动作 JSON。

- 内置方案随应用提供，只读且不能覆盖或删除；可使用“另存为”创建用户副本。
- 用户方案可保存、重新加载和删除，文件扩展名为 `.wacscheme`。
- 方案使用 UTF-8 JSON，保存时先写临时文件再原子替换；加载时严格检查重复字段、未知
  字段、类型、大小、时间戳和源码语法。
- 单个方案文件最大 512 KiB，源码最大 100000 个字符。

内置方案包括温和连点 20 次、双击、定点右键、重复空格键、持续连点，以及变量与
复用函数示例。定点示例中的坐标只是演示值，必须先按自己的屏幕与目标修改。

## 校验与安全限制

编辑器校验失败时会报告具体行号和列号；未通过编译的源码不会启动。默认限制如下：

| 项目 | 默认上限 |
| --- | ---: |
| 源码长度 | 100000 个字符 |
| 语句数量 | 10000 条 |
| 循环嵌套 | 16 层 |
| 函数调用深度 | 32 层；禁止递归 |
| 单个 `repeat` 次数 | 10000 次 |
| 单条鼠标点击次数 | 10000 次（同时受展开动作上限约束） |
| 单次鼠标按住时长 | 60000 ms |
| 单次键盘/组合键按住时长 | 60000 ms |
| 单个组合键的按键数量 | 16 个 |
| 编译展开后的输入动作 | 100000 个 |
| 单次或连续等待 | 86400000 ms（24 小时） |
| 一次运行时长 | 3600 秒（1 小时） |
| 一次运行执行的输入动作 | 100000 个 |

达到运行时长或动作数上限时，方案会自动停止并报告错误。有限前缀、末尾等待和无限
循环在整个运行期间共用同一互斥状态，因此不会在两段之间误启动录制、回放或连点。
停止、Esc、异常和窗口关闭都会等待底层输入释放完成后再结束运行状态。

以下内容不是该语言的一部分，并会被拒绝或当作未知命令：

- Python 表达式、`eval`、`exec`、导入、对象属性访问、文件和网络访问；
- 运行时条件表达式、字符串/对象/列表变量、函数返回值和动态按键名；随机等待仍只
  支持受限的 `next T random D` 均匀偏移；
- 无上限的永久按住；显式 `key down` 会在本次运行结束时强制释放；
- 图像识别、控件查找、窗口标题定位和相对窗口坐标。

## 使用建议

- 第一次运行新方案时，先使用少量重复次数，并在无副作用的测试窗口中验证。
- `while true` 中保留 `next`，并从较长间隔开始逐步调整。
- 多次点击优先用一条带 `count`/`interval` 的鼠标命令；复杂的多动作流程仍使用
  `repeat`。需要等待下一条不同命令时用 `after` 或单独的 `next`，不要把它误当成
  同一条多击之间的 `interval`。
- 定点坐标可能因窗口移动、显示器布局、DPI 或目标程序画面变化而失效。
- 不要在方案运行期间输入密码或处理真实消息；自动输入会作用于当前接收输入的窗口。
- 目标程序若以更高权限运行，Windows 可能阻止普通权限应用注入输入；本工具不会绕过
  UAC、安全桌面、反作弊或其他系统保护。
