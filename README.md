# WinActionRecorder

WinActionRecorder 是一款面向 Windows 10/11 的本地鼠标键盘动作录制、回放、连点与
自定义指令工具。录制脚本使用绝对屏幕坐标；连点器还可记住取点在屏幕中的相对位置，
在切换到限制鼠标范围的全屏程序后按当前活动区域适配。应用不联网、不上传动作，也
不包含远程控制、隐蔽运行、权限绕过、遥测或安全软件规避功能。

> **隐私提示：**录制可能包含密码、聊天内容等敏感输入，请勿在录制期间输入敏感
> 信息。所有数据仅保存在本地。JSON 脚本本身可能含有实际按键内容，请像保护普通
> 敏感文件一样保护它。

## 功能

- 全局录制鼠标移动、左/右/中键按下与释放、滚轮，以及键盘按下与释放。
- 完整事件和时序可自然表达单击、双击、拖拽和组合快捷键。
- 鼠标移动采用时间与距离阈值节流，采样间隔默认 20 ms。
- 按动作延迟回放，支持 0.1～10.0 倍速、固定次数或无限循环、循环间隔和倒计时。
- 独立鼠标连点器支持左/右/中键、固定或无限次数、10～60000 ms 间隔、暂停继续、
  跟随当前光标或固定坐标；点击“在屏幕上选取位置”后会压暗全部显示器，用户在目标
  处单击即可完成取点，右键或 Esc 可取消。
- 通过全屏取点保存的连点坐标可选择“切屏后按当前画面等比适配”。全屏程序使用
  `ClipCursor` 限制鼠标范围时，连点器会把取点在原屏幕中的相对位置映射到当前活动
  区域；普通录制脚本的回放仍严格使用绝对坐标，不会自动缩放。
- 自定义模式提供行式指令编辑器和像素化“鼠标指令积木”。鼠标单击可分别设置按住
  时长、单条点击次数、点击间隔、完成后等待和固定坐标；积木会同步显示 DSL 与
  “按下→保持→释放”流程，并可插入或更新当前代码行。语言还支持等待、鼠标移动、
  单键、编译期数值变量、带单位算术、参数化函数、固定次数循环、`while true` 和
  `break`。
- 随附温和连点、双击、定点右键、重复空格和持续连点等内置只读示例；内置示例可
  另存为用户方案，用户方案可继续编辑或删除。
- 可一键“跳过鼠标移动轨迹（保留点击位置）”：回放会省略移动事件及其延迟，
  点击和滚轮仍直接定位到各自动作记录的坐标；可设置释放到下一次按下之间的最小
  点击间隔，取消勾选即可完整恢复。
- 支持暂停、继续、停止和 Esc 紧急停止；所有结束路径都会尝试释放程序按住的键和
  鼠标按钮。
- 可启用、禁用、编辑、删除和上下移动动作；调整后自动重新计算时间偏移。
- 动作轨道使用虚拟数据模型，只创建当前可见单元格；即使载入 10,000 条动作，也不会
  为整张表预先生成数万个控件。状态栏与播放可用性使用同一份动作清单缓存，频繁进度
  更新不再反复扫描整份脚本。
- 读写带版本和显示器元数据的 UTF-8、格式化 JSON，并严格验证外部字段。
- 使用 Win32 原生物理像素坐标记录虚拟桌面和显示器布局，与 pynput 的录制/回放坐标
  保持一致；回放前检查数量、位置、尺寸和缩放比例，不一致时默认取消。
- 清爽的 16-bit 像素工具台式中文 GUI，使用深蓝硬边框、阶梯阴影、像素图标和青色、
  薄荷绿、珊瑚红状态色；窄窗口使用双层操作栏并压缩右侧控制台，参数页只做纵向滚动。
  自定义页把高频点击参数保持在首屏，将坐标、命令后等待和详细流程收进“更多参数”，
  保留更大的源码核对区域。应用标题栏、任务栏、EXE 和顶部品牌位统一使用蓝青色像素
  录制图标。QSettings 保存窗口大小和非敏感运行设置。
- F8 切换录制；F9 按当前页面运行/暂停/继续普通回放或自定义方案；F10 开始/停止连点；Esc 紧急停止
  当前录制、普通回放、连点或自定义方案；控制快捷键不会写入动作列表。
- 本地轮转日志只记录运行状态与脱敏错误，不记录实际字符或完整动作。

## 环境要求

- Windows 10 或 Windows 11
- Python 3.11 或更高版本（建议使用 64 位官方 Python）
- 桌面交互会话

如果目标程序以管理员身份运行，Windows 的完整性级别机制可能阻止普通权限程序向它
发送输入。这时可以由用户自行以管理员身份启动 WinActionRecorder；程序不会尝试绕过
权限，也无法在 UAC 安全桌面上工作。

.\.venv\Scripts\Activate.ps1

```powershell
python main.py
```

安装为可编辑包后也可使用：

```powershell
win-action-recorder
```

首次启动会显示简短说明和隐私提示。保持窗口打开后，全局快捷键在窗口失去焦点时仍

查看已有脚本。

## 核心使用方法

1. 单击“录制”或按 F8，等待录制倒计时结束。
2. 在目标程序执行动作；再次按 F8 或在窗口中单击“停止”结束录制。
3. 在动作表中启用、禁用、编辑、删除或调整动作顺序。
4. 设置循环次数（或无限循环）、循环间隔、速度和回放倒计时。
5. 如果只需要若干固定位置的点击，可勾选“跳过鼠标移动轨迹（保留点击位置）”，
   省略录制时缓慢移动产生的轨迹和等待；再用“跳过轨迹时点击间隔”设置各次点击
   之间的最小等待（默认 200 ms，可设为 0～60000 ms）。
6. 在回放页单击“播放”或按 F9。回放期间 F9 暂停/继续，Esc 随时紧急停止；切到
   自定义页时，F9 改为运行、暂停或继续当前方案。
7. 使用“保存”将动作写入本地 JSON；以后可“打开”继续编辑或回放。

录制、普通脚本回放、鼠标连点和自定义方案运行彼此互斥。暂停、停止、异常和窗口关闭
都会进入同一类安全清理逻辑，尽力释放由程序按下但尚未释放的输入。

“跳过鼠标移动轨迹”是非破坏性的应用偏好：不会删除动作、改变每个动作的启用状态，
也不会写入动作脚本 JSON。该偏好及点击间隔由 QSettings 保存，取消勾选后原轨迹立即
恢复。点击间隔从一次鼠标手势的最后一个按钮释放完成算到下一次新手势按下；它不会
延长同一次点击的按住时长，也不随播放速度倍率缩放。轮次间已有的循环间隔会计入该
最小间隔。
如果只想为某两个点击设置特殊间隔，可编辑后一个“鼠标按钮按下”动作的动作前延迟；
全局点击间隔只负责补足最小值，不会缩短更长的原始延迟。

### 鼠标连点

1. 打开右侧“鼠标连点”页，选择左键、右键或中键。
2. 设置点击间隔和次数；“无限连点”会忽略固定次数。间隔指一次释放完成到下一次
   按下之间的等待，首次点击前不会额外等待。
3. “跟随当前光标”不会主动移动鼠标；选择“固定坐标”后，单击“在屏幕上选取位置”，
   所有显示器会暂时变暗。取点按钮不需要保持按住：界面变暗后，在目标位置单击一次
   即可记录坐标；右键或 Esc 取消且不改动原坐标。多显示器和负坐标会按 Windows 物理
   像素坐标记录；确认目标前“开始连点”保持禁用。
4. 单击“开始连点”后可利用默认 3 秒倒计时移动到目标，也可在目标上直接按 F10。
   运行中可暂停/继续，再按 F10 或“停止”结束；Esc 始终执行紧急停止。

连点器每次完成按下和释放后才增加计数，有限次数的最后一次释放后不会再等待。配置
仅由 QSettings 保存，不会写入动作 JSON，也不会把脚本标记为已修改。为防止零间隔失控，
最小间隔为 10 ms；系统与目标程序负载仍可能造成抖动。固定坐标支持多显示器负坐标，
启动前会按当前真实显示器区域校验，原生移动后也会核对实际位置；显示器断开、取点时
显示器拓扑发生变化或坐标落入显示器之间的空白区域时，会在按下鼠标前停止。

“切屏后按当前画面等比适配”只作用于通过全屏取点器得到、带屏幕锚点的连点坐标。若
倒计时期间切到全屏程序，而该程序用 Windows `ClipCursor` 把光标限制在较小活动区域，
连点器会保留目标在原屏幕中的横纵相对位置并映射到该区域。若当前鼠标活动范围仍包含
原屏幕，则继续使用原绝对坐标；关闭该选项也始终使用原绝对坐标。该适配不会影响普通
录制脚本回放，录制回放仍会严格检查显示器配置并使用保存的绝对物理像素坐标。使用前
仍应在无副作用窗口中验证。

### 自定义指令与方案

1. 打开“自定义”页，从方案列表选择内置示例，或新建一个空白方案。
2. 可直接在编辑器中每行写一条命令，也可用“鼠标指令积木”设置按钮、按住时长、
   次数和相邻点击间隔；“更多参数”中可继续设置结束后等待和固定坐标，并核对详细流程
   与 DSL，再插入或更新当前行。使用“校验”查看精确到行、列的语法错误。更新可识别
   行时会保留缩进、可选 `/` 前缀和尾注释；无法无损表示的合法数值会保持源码不变并
   禁用更新。
3. 单击“运行方案”。运行中可暂停、继续或停止；`while true` 方案可用停止按钮或 Esc
   随时结束。
4. 使用“保存”更新用户方案，或使用“另存为”从内置示例创建可编辑副本。内置示例
   本身只读、不可覆盖和删除。

最小示例：

```text
# 左键点击 10 次；每次按住 35ms，两次点击之间等待 200ms
mouse left[last:35ms, count:10, interval:200ms]
```

持续运行示例：

```text
while true {
  mouse right
  next 0.5s random 0.25s
}
```

`next 0.5s random 0.25s` 会在每次执行时重新随机等待 `0.25s～0.75s`；偏移量
不能大于基础等待，所以不会产生负等待。

变量、算术与复用函数示例：

```text
let rounds = 3
let gap = 240ms

function burst(times, delay) {
  repeat times {
    key f[last:delay / 8]
    next delay random delay / 4
  }
}

call burst(rounds, gap)
```

数值表达式支持 `+ - * / %` 和括号，`1s / 4` 会得到 `250ms`。函数参数目前是
数值，可用于等待、随机偏移、重复次数、坐标、滚轮量、点击参数和按键保持时间；函数
在运行前受控展开，递归、过深调用和超出动作上限的展开都会被拒绝。

参数化单击的完整形式为
`mouse left[last:10ms, count:2, interval:80ms, after:200ms] at X Y`；旧的
`mouse left` 仍保持默认按住 20ms 的兼容行为。语言还支持 `mouse move X Y`、
`mouse scroll DX DY`、`key f[last:80ms]`、`key down/up ctrl`、
`hotkey ctrl shift s[last:80ms]`、`next T random D`、`break`、以 `/` 开头的命令，
以及 `#` 或 `//` 注释。算术由语言自身的受限解析器处理，不会执行 Python；语言也不
支持导入、对象访问、文件/网络访问或任意代码执行。
完整语法、按键名、资源限制和更多例子见
[自定义指令语言手册](docs/CUSTOM_LANGUAGE.md)。

## 默认全局快捷键

| 快捷键 | 行为 |
| --- | --- |
| F8 | 开始或停止录制 |
| F9 | 按当前页面开始、暂停或继续普通回放/自定义方案；已有任务运行时优先控制该任务 |
| F10 | 开始或停止鼠标连点 |
| Esc | 紧急停止录制、普通回放、连点或自定义方案，并取消尚未结束的倒计时 |

录制器会过滤这些控制键的按下与释放。回放引擎在注入每个输入时短暂抑制自身快捷键
处理，避免脚本中的 F8/F9/F10/Esc 反过来控制应用。

## JSON 格式

文件采用 UTF-8 编码和缩进格式，顶层结构如下（字段可能随兼容版本扩展）：

```json
{
  "format_version": 1,
  "app_version": "0.9.1",
  "created_at": "2026-08-02T12:00:00+00:00",
  "screen_config": {
    "virtual_desktop": {"x": 0, "y": 0, "width": 1920, "height": 1080},
    "monitors": [
      {
        "id": "DISPLAY1",
        "name": "DISPLAY1",
        "x": 0,
        "y": 0,
        "width": 1920,
        "height": 1080,
        "is_primary": true,
        "device_pixel_ratio": 1.0
      }
    ],
    "primary_monitor": "DISPLAY1",
    "device_pixel_ratio": 1.0
  },
  "recording_settings": {
    "mouse_move_sample_interval_ms": 20
  },
  "actions": [
    {
      "id": "独立标识",
      "type": "mouse_move",
      "offset_ms": 0,
      "delay_ms": 0,
      "enabled": true,
      "params": {"x": 100, "y": 100}
    }
  ]
}
```

动作类型包括 `mouse_move`、`mouse_button`、`mouse_scroll`、`key_down` 和
`key_up`。加载器不会直接信任文件内容：缺失字段、非法类型、负延迟、无效参数、超出
安全边界的坐标和不支持的版本都会转成可读错误，而不会使应用崩溃。

## 打包 Windows EXE

安装依赖后，在项目根目录运行：

```powershell
python -m PyInstaller --clean --noconfirm build.spec
```

生成结果位于：

```text
dist\WinActionRecorder.exe
```

EXE 为窗口模式单文件入口，不会弹出控制台。复制该文件即可在兼容的 Windows 机器上
运行；动作脚本不会被打包进 EXE，也不会被自动上传。首次在新机器使用时，仍应按下面
的清单进行人工验收。

## 人工验收清单

请只在可安全操作的测试窗口中验收，避免输入真实密码或发送真实消息。

- [ ] F8 在应用失焦时能开始与停止录制，且动作列表中没有 F8 按下/释放。
- [ ] 左键、右键和中键的按下与释放顺序正确。
- [ ] 双击的两组按下/释放及时间间隔正确。
- [ ] 勾选“跳过鼠标移动轨迹”后，固定位置点击直接命中且缓慢移动等待消失；取消
  勾选后完整轨迹恢复，原本手动禁用的动作没有被误启用。
- [ ] 将“跳过轨迹时点击间隔”分别设为 0、200 和 1000 ms，确认相邻点击间隔生效，
  且鼠标按下到释放的时长没有被额外延长。
- [ ] 连点器分别使用左、右、中键和有限次数，确认按下/释放严格成对，完成计数准确。
- [ ] 将连点间隔设为 10、100 和 1000 ms，确认首次点击立即发生、最后一次释放后没有
  尾随等待；长间隔中按 F10 或 Esc 能快速停止。
- [ ] 验证“跟随当前光标”不主动移动鼠标；固定坐标取点会压暗所有显示器，目标处左键
  确认，右键或 Esc 取消且保留原坐标；连点时每次点击前回到所选位置，并在多显示器
  负坐标上正确工作。
- [ ] 通过取点器记录一个屏幕边缘目标，开始倒计时后切入会限制鼠标范围的全屏程序；
  开启相对适配时确认点击命中画面中的同一相对位置，关闭后确认仍使用原绝对坐标。
- [ ] 无限连点可暂停/继续，暂停期间没有新点击；停止、异常和关闭窗口后没有鼠标按钮
  保持按下。
- [ ] 自定义页能加载每个内置示例；把内置示例另存为用户方案后可编辑、保存、重新加载
  和删除，且内置示例本身不能被覆盖或删除。
- [ ] 分别运行有限 `repeat`、包含 `break` 的循环和 `while true` 方案；确认暂停期间没有
  新动作，继续后从未执行的位置恢复，Esc 可快速停止且没有按键或鼠标按钮保持按下。
- [ ] 输入未知命令、非法坐标、循环外 `break` 和无限循环后的不可达命令，确认编辑器
  显示明确的行列位置且不会启动方案。
- [ ] 用鼠标指令积木生成并回填 `last`、`count`、`interval`、`after` 与固定坐标；分别
  测试 10ms/100ms/1000ms 按住时长、单击/双击/多击，并确认更新当前行保留缩进。
- [ ] 验证 `interval` 只位于同一条多次点击的两次释放/按下之间，`after` 位于最后一次
  释放之后且会与后续 `next` 累加；暂停、Esc 或关闭发生在长按期间时按钮仍被释放。
- [ ] 验证 `next 0.5s random 0.25s` 每次重新抽样且始终位于 0.25～0.75 秒；暂停不消耗
  剩余等待，Esc 能立即中断，偏移大于基础等待时校验明确拒绝。
- [ ] 按住鼠标移动后释放可正确完成拖拽，停止或暂停不会遗留按住状态。
- [ ] 垂直和水平滚轮方向、步数正确。
- [ ] 英文字符、数字、Shift、Ctrl、Alt、Win、功能键、方向键、Enter、Tab、

## 隐私、安全与日志

- 应用无网络功能、无遥测、无账户系统，也不会扫描其他文件。
- JSON 动作脚本由用户明确保存；它可能暴露实际按键、坐标和操作时间。
- 默认日志目录为 `%LOCALAPPDATA%\WinActionRecorder\logs`，日志采用轮转保存，不写入
  实际键入字符或完整动作参数。
- 请勿将本工具用于未经授权的电脑、账户或流程；不要在录制期间输入敏感信息。
- 工具不会提升权限、绕过 UAC、隐藏自身或规避安全软件。

## 已知限制

- 普通录制脚本只使用 Win32 物理像素绝对坐标，不做图像识别、目标控件定位或跨配置
  自动缩放；显示器布局、DPI 或窗口位置改变后会警告，但明确继续时坐标仍可能错位。
- 连点器的相对适配仅针对“全屏取点 + `ClipCursor` 活动区域”这一场景，不会识别目标
  窗口、按钮或画面内容；窗口化程序移动、游戏画面拉伸或活动区域比例变化时，映射点
  仍可能不是用户想要的控件。
- 跳过移动轨迹时，按下点和释放点不同的拖拽会变成从起点到终点的瞬时拖拽；需要
  平滑轨迹的脚本应取消该选项。
- “跳过轨迹时点击间隔”设置较大时，原本的双击可能被识别为两次单击；双击脚本应
  使用较小间隔或直接编辑相应动作延迟。
- 连点器按固定时间和坐标注入鼠标事件，不识别目标控件；目标移动、窗口遮挡或光标被
  用户移动时，跟随模式可能点击到不同位置，固定坐标也可能命中错误窗口。
- 自定义指令使用 `hotkey ctrl c` 表达组合键，并支持受限的显式按下/释放、滚轮、
  数值变量、算术和函数；仍不提供运行时条件判断、字符串参数、图像识别、窗口查找或
  任意 Python 执行。
- 自定义指令的毫秒时长按 1 倍运行，不提供宏级速度倍率；Windows 调度、系统负载和
  目标程序响应仍可能产生毫秒级抖动，不能当作硬实时计时器。
- 字符回放依赖回放时的 Windows 键盘布局和输入法状态；复杂 IME 组合过程未做语义级
  重建。
- Windows 安全桌面、部分游戏/反作弊环境、原始输入应用和更高权限进程可能拒绝全局
  监听或输入注入。
- 系统负载和目标程序响应会造成毫秒级抖动，无法提供硬实时保证。
- 录制器保存输入事件，不理解目标应用语义；请先在无副作用的测试环境验证脚本。
